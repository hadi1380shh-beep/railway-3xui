# 🇮🇷 ماشین بازی ایرانی — Iranian Car Game

یک بازی رانندگی سه‌بعدی تحت وب برای موبایل و دسکتاپ، با خودروهای ایرانی
(پیکان، پراید و سمند) و گرافیک سه‌بعدی طبیعی (سایه، نور، شهر ایرانی، برج آزادی،
درخت و ساختمان).

## 🎮 اجرای بازی

فایل `index.html` یک فایل **کاملاً مستقل** است و به هیچ اینترنت یا CDN‌ای نیاز ندارد
(کتابخانهٔ سه‌جی‌اس داخل همان فایل قرار گرفته است). کافی است:

- روی کامپیوتر: فایل `index.html` را در مرورگر باز کن، **یا**
- با سرور محلی: `npm install` سپس `npm run serve` و باز کردن `http://localhost:8080`
- روی موبایل: فایل را روی هر هاست استاتیکی (GitHub Pages، Netlify، Vercel و…) بگذار و باز کن.

> لینک مستقیم بازی روی GitHub Pages:
> `https://USERNAME.github.io/railway-3xui/iran-car-game/index.html`

## 🕹️ روش بازی

- **گاز** 🟢 و **توقف/دنده‌عقب** 🔴 با دکمه‌های صفحه (یا کلیدهای `W` / `S`)
- **فرمان** با دکمه‌های ◀ ▶ (یا کلیدهای `A` / `D`)
- **فرمان با چرخش گوشی**: دکمهٔ 📱 را بزن (با حسگر ژیروسکوپ گوشی)
- 🪙 سکه‌ها را جمع کن تا امتیاز بگیری
- 🚙 به ماشین‌های دیگر نخور (۳ جان داری)
- ⏸️ دکمهٔ توقف، و 🔊 برای قطع/وصل صدا

## 🛠️ ساخت دوباره (برای توسعه‌دهنده‌ها)

سورس خوانای بازی در `src/game.js` است. برای باندل کردن دوبارهٔ `index.html`:

```bash
npm install
npm run build
```

تست خودکار بدون مرورگر (شبیه‌سازی کامل بازی در Node):

```bash
node tools/harness.mjs
```

## 📄 ساختار پوشه

```
iran-car-game/
├── index.html            ← فایل نهایی بازی (مستقل و قابل انتشار)
├── index.template.html   ← قالب HTML
├── src/game.js           ← سورس اصلی بازی
├── build.mjs             ← اسکریپت باندل (esbuild + three.js)
├── tools/                ← سرور محلی و ابزار تست
└── package.json
```

ساخته‌شده با [three.js](https://threejs.org) — گرافیک WebGL با سایه‌های نرم، نورپردازی
طبیعی و مه افقی.
